# Final claim boundaries

## Safe claims

- The product is core-first/modular: map, timeline, structured content, exploration, exams and dashboard/account features retain value without generative AI.
- The exact-year UI is visible and supports signed integers within the runtime model range; `0` is “Công Nguyên”; initial Cesium orientation is deterministic.
- Six exam modes use server-authoritative scoring. No canonical answer-key leakage was found in the reviewed public artifacts.
- Password change/reset invalidates old tokens on their next protected request through `authVersion`.
- RAG-01 has 60 retrieval cases (59 scored + 1 control) and a separate 27-task/54-output paired generation benchmark.
- On this fixed source-aligned benchmark, RAG produced more semantically acceptable outputs than Gemini-only after source-bound owner adjudication: 23/27 versus 13/27.
- RAG-02 is a bounded runtime factual guard for 10 curated critical facts, with controlled failure after at most one repair.
- GIS is an optional/lazy 34-unit modern administrative reference; it is not historical reconstruction.
- PERF-01 found no safe meaningful improvement and the nested-lazy attempt was reverted.

## Unsafe claims

- Fully offline, local-first, or AI-independent deployment.
- ML/adaptive/AI dashboard personalization.
- Instant push logout on all devices.
- No answer-like field exists anywhere in the repository.
- RAG universally outperforms Gemini, guarantees correctness, or covers all Vietnamese history.
- All hallucinations/facts are solved or automatically verified; 100% historical accuracy.
- The 60 retrieval cases are generation runs, or the 394 tests are benchmark cases.
- GADM reconstructs period-correct historical boundaries or has a verified license.
- A final 77.4% performance improvement.
- 3D has experimentally proven educational effectiveness.

## Limitations that must remain visible

No learner study; no proven 3D learning effect; Gemini/Viettel external dependency; fixed/small RAG benchmark; 10-fact registry coverage; incomplete exam-source academic provenance; modern-not-historical GIS with unverified license; reverted performance experiment.
