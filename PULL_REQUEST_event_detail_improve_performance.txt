TITLE
=====
Improve Event Detail loading stability and Lighthouse performance

SUMMARY
=======
- Replace the full-screen loading spinner with a geometry-preserving skeleton shell.
- Resolve the large layout shift on the Event Detail page (CLS 0.369 -> 0.0002).
- Fix several accessibility issues flagged by Lighthouse (color contrast + heading order).
- Preserve all Event Detail functionality and the responsive layout (desktop / tablet / mobile).

PROBLEM
=======
Baseline Lighthouse desktop median (3 runs, production build, local lab):

| Metric         | Baseline |
|----------------|----------|
| Performance    | 63       |
| LCP            | 1.733 s  |
| TBT            | 0.532 s  |
| CLS            | 0.369    |
| Accessibility  | 94       |
| Best Practices | 100      |

The page swapped between two completely different geometries while loading:
a full-viewport centered spinner (min-h-screen) replaced by the full event
content, producing one large layout shift and an extra full-page layout pass.

ROOT CAUSE
==========
CDP trace + Lighthouse layout-shifts audit:

- A single large LayoutShift (~0.3694) at the moment the API response arrives:
  old_rect [582, 569, 170, 20] (the loading text) -> new_rect [0, 127, 1335, 813]
  (the main content container `div.mx-auto.max-w-[1440px]`).
- Consistent evidence: on the run where the cached API response rendered before
  the spinner was painted, CLS was 0.000; on runs where the spinner was visible,
  CLS was 0.369.
- NOT caused by: unsized images (unsized-images audit passes), the TTS player,
  or font swapping.

CHANGES
=======
1. Replace the full-screen spinner with an Event Detail skeleton shell
   (EventDetailPage.tsx).
2. Preserve approximate page geometry while event data loads:
   sticky breadcrumb, content grid, desktop sidebar, hero skeleton
   (min-height 375px) and TTS card skeleton (min-height 86px), measured from
   the real rendered DOM.
3. Fix color contrast of Event Hero metadata labels ("Thời gian" / "Địa điểm")
   (EventHero.tsx).
4. Fix color contrast of SectionHeader indices ("01", "02", ...)
   (SectionHeader.tsx + new `--admin-accent-text` theme variable in index.css).
5. Fix color contrast of the active TOC index in the Event Detail sidebar
   (EventDetailSidebar.tsx).
6. Fix heading hierarchy in Event Sources: h4 -> h3 with identical typography
   (EventSources.tsx).
7. Add a regression test for the skeleton loading state
   (frontend/src/pages/__tests__/EventDetailPage.test.tsx).

LIMITATIONS
===========
- Lighthouse numbers are local lab measurements; do not interpret them as
  production Core Web Vitals.
- The published dataset currently provides hero thumbnails for all 361 events,
  so a true no-thumbnail event variant was unavailable for real-data
  verification (skeleton heights are tuned to measured desktop geometry).
- TBT / Performance remain environment-sensitive metrics.
- This change only touches the Event Detail page; other pages (e.g. Map/Cesium)
  are out of scope.
