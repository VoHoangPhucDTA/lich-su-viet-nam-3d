TÓM TẮT
=======
- Thay màn hình loading (spinner toàn màn hình) bằng skeleton giữ nguyên hình học trang.
- Xử lý layout shift lớn trên trang Chi tiết sự kiện (CLS 0.369 → 0.0002).
- Sửa một số vấn đề accessibility do Lighthouse phát hiện (tương phản màu + thứ tự heading).
- Giữ nguyên toàn bộ chức năng trang Chi tiết sự kiện và layout responsive (desktop / tablet / mobile).

một lần layout toàn trang thừa.

NGUYÊN NHÂN GỐC
===============
Bằng chứng từ CDP trace + audit layout-shifts của Lighthouse:

- Một LayoutShift lớn duy nhất (~0.3694) xảy ra đúng lúc API trả về:
  old_rect [582, 569, 170, 20] (chữ "Đang tải dữ liệu sự kiện…") → new_rect [0, 127, 1335, 813]
  (container nội dung chính `div.mx-auto.max-w-[1440px]`).
- Bằng chứng nhất quán: ở lần chạy mà API cache nóng render nội dung trước khi spinner kịp
  vẽ, CLS = 0.000; ở các lần chạy có spinner hiển thị, CLS = 0.369.
- KHÔNG phải do: ảnh không đặt kích thước (audit unsized-images pass), TTS player, hay font swap.
